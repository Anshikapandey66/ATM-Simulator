# 🏦 Python ATM Simulator

A simple **ATM Simulator** built using Python.  
This project simulates basic ATM operations through a command-line interface.

## ✨ Features

- 🔐 PIN authentication
- 💰 Check account balance
- 💵 Deposit money
- 🏧 Withdraw money
- 🔑 Change PIN
- 🚫 Maximum 3 PIN attempts
- ✅ Input validation
- 👋 Exit safely

## 🛠️ Technologies Used

- Python 3
- Loops
- Conditional Statements
- Functions
- Exception Handling
- User Input
